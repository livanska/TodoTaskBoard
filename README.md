# 📝 Todo Task Board

A modern, drag-and-drop task board built with React, Redux Toolkit, and Atlassian's `pragmatic-drag-and-drop`. Organize your tasks in customizable columns with a clean and responsive UI.

[🌐 Live Demo](https://livanska.github.io/TodoTaskBoard)

---

## ✨ Features

-   🧱 Drag & drop tasks between columns
-   🪄 Create, rename, and delete columns
-   📝 Add, edit, and remove tasks
-   💾 Persistent local storage sync
-   ⚡️ Smooth interactions via Atlassian drag-and-drop primitives
-   🧠 State managed with Redux Toolkit
-   🎨 Styled with `styled-components`

---

## 🚀 Tech Stack

-   **React 19**
-   **Redux Toolkit**
-   **TypeScript**
-   **@atlaskit/pragmatic-drag-and-drop**
-   **styled-components**
-   **gh-pages** (deployment)

---

## 🛠 Local Development

```bash
# Clone the repo
git clone https://github.com/livanska/TodoTaskBoard.git
cd TodoTaskBoard

# Install dependencies
npm install

# Start development server
npm start
```
